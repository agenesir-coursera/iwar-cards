# iWAR Cards

Static site for browsing iWAR (Item Wins Above Replacement) values across Coursera course items.

## How it works

The site loads an encrypted data file (`iwar_data.json.enc`) and prompts the viewer to paste their `iwar_key.json`. The key contains the AES-256 decryption key plus the spec/course/item name lookups. Decryption happens in browser memory only.

## Deploying the data file

The `iwar_data.json.enc` file is generated by the iWAR notebook in Databricks. After running Section 9 of the notebook, download the encrypted file from the Unity Catalog volume and commit it to this repo at the root path. Then `git push` and GitHub Pages will redeploy automatically.

## Local preview

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

The site fetches `./iwar_data.json.enc` by default. Override with `?data=https://...` if you host the encrypted file elsewhere.
